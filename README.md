# cajero-automatico-javafx
Aplicación de cajero automático (ATM) desarrollada en Java con JavaFX, que permite realizar operaciones bancarias básicas: depósitos, retiros, transferencias, recargas telefónicas, pago de servicios y consulta de movimientos. Desarrollado como proyecto de portafolio profesional.

## Características
- **Autenticación por Token/NIP**.
- **Depósitos en efectivo**.
- **Retiros de saldo** con validación de fondos.
- **Transferencias entre cuentas** (origen y destino).
- **Recargas telefónicas** (Telcel, AT&T, Movistar, Unefon).
- **Pago de servicios** con número de servicio de 12 dígitos.
- **Consulta de movimientos** filtrados por tipo (depósitos, retiros, transferencias enviadas/recibidas).
- **Interfaz gráfica amigable** con diseño responsivo y colores corporativos.
- **Manejo de transacciones** con commit/rollback para integridad de datos.
- **Mensajes de error y éxito** con JavaFX Alert.

## Tecnologías Utilizadas
- **Java 21** (LTS).
- **JavaFX 21** (GUI).
- **MySQL 8.0+** (Base de datos).
- **JDBC** (Conector MySQL 8.0).
- **Maven** (Opcional, se puede usar sin Maven).
- **VSCode** (Recomendado) o cualquier IDE con soporte para JavaFX.
